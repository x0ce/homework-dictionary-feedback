# 小學字典：問題回報與功能建議

這裡接收 iPhone／iPad「小學字典」的使用回饋。程式碼與學生教材不放在此公開儲存庫。

## 如何回報

請由家長或老師協助。在 App 的字詞詳情點「回報這個字詞的問題」，或在「資料來源與說明」點「回報錯字或功能問題」。填寫並預覽後，前往 GitHub 登入及確認提交。

也可以直接使用本儲存庫的 Issues，選擇「字典問題與建議」。類型包括錯字／字義／注音、功能缺失、功能失效及新增／刪減／優化建議。

**此處公開可見。請勿填入學生姓名、學校、電話、帳號、住址，或上傳含個人資料的作業照片。** 不需要提供裝置序號或 Apple ID。

請提供：發生問題的字詞及讀音、來源辭典或 AI 例句、重現步驟、預期結果、App／系統／資料版本。請先搜尋是否已有相同回報。

## 如何追蹤

提交後保留 Issue 連結，或透過 GitHub 的訂閱通知追蹤。維護者會判斷、重現與安排修正；可能要求補充資訊，或標記為重複／暫不處理並說明理由。

修正會在私人程式碼儲存庫建立 PR 並測試。公開 Issue 不需要也不會包含私人程式碼；維護者會在這裡說明修正結果與可取得修正的版本。合併程式碼不等於已發佈；收到更新並確認修正後才結案，仍有問題可重新開啟。

## 資料來源與 AI

教育部官方原文與 App 補充、AI 生成內容分開呈現。AI 可能用錯字義，不能視為教育部原文或教師審閱內容。疑似官方錯字會先比對來源，必要時回報官方；不直接改寫原文冒充新版。

目前仍為開發／測試版本，尚未在 App Store 上架。正式發佈後會在此說明版本與修正項目。
